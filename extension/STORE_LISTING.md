# Chrome Web Store Listing

## Short description (132 chars max)
Auto-captures accepted LeetCode and Codeforces submissions and logs them to your Focus ASTU CP Hub profile.

## Full description
Focus ASTU CP Hub — Browser Extension

Automatically tracks your competitive programming progress without any manual effort.

WHAT IT DOES
• Detects accepted submissions on LeetCode and Codeforces in real time
• Captures the problem, language, and your code
• Posts the submission to your Focus ASTU CP Hub profile instantly
• Shows a notification confirming each logged solve

SUPPORTED PLATFORMS
• LeetCode (all languages)
• Codeforces (all languages)

SETUP (takes 30 seconds)
1. Install this extension
2. Log in to your Focus ASTU CP Hub account
3. Go to Settings → generate an API key
4. Click the extension icon → paste your API key → save

After setup, just solve problems normally — the extension handles the rest.

PERMISSIONS
• Storage: saves your API key locally (never sent anywhere except your own hub)
• Notifications: shows confirmation when a solve is logged
• Alarms: used for retry logic if the hub is temporarily unreachable
• Host permissions for leetcode.com and codeforces.com: required to detect submission verdicts on those pages

PRIVACY
Your code and submission data is sent only to the Focus ASTU CP Hub backend that you configure. No data is sent to any third party.

This extension is built for students of Adama Science and Technology University (ASTU) participating in the Focus competitive programming club.
